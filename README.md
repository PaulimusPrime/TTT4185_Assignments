# TTT4185_Assignments
This repository aims to track my assignment progress in NTNU subject TTT4185 Machine Learning for Signal Processing.

Assignment 1 introduces Fourier Analysis to interpret wav files, and to identify vowels and phonetics

Assignment 2 aims to train a classifier in order to identify certain vowels, based on provided training data.

Assignment 3 provided an introductory experience into neural networks, and relevant techniques and perspectives, when using said technology.
